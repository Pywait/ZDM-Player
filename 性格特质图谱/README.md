# 性格特质图谱 · Personality Trait Radar

一个纯前端的性格自评小工具。基于 **200 对相反性格特质**，按 **6 大分类**（社交互动、情绪情感、认知与思维、意志与行动、态度与价值观、自我认知与成长）组织，通过 **五级选择** 记录倾向，并实时生成六张分类雷达图。

- **零依赖**：单个 HTML 文件，双击即可在浏览器中使用。
- **数据本地化**：所有选择自动保存在浏览器 `localStorage` 中，也可导出为 JSON 文件备份或分享。
- **可视化反馈**：Canvas 绘制的雷达图随选择即时更新。

---

## 功能特性

- **五级选择**：每对特质提供 5 个选项，从左到右依次为：
  - `◀◀` 完全偏向左端
  - `◀` 比较偏向左端
  - `●` 中间 / 不确定 / 两者之间
  - `▶` 比较偏向右端
  - `▶▶` 完全偏向右端
- **分类折叠**：六大分类可独立展开或收起，方便快速定位。
- **实时雷达图**：每个分类对应一张雷达图，轴为子分组名称，得分越高越靠外。
- **自动保存**：编辑后延迟 600ms 自动保存至浏览器本地。
- **导入 / 导出**：支持将当前档案导出为 `.json` 文件，也可导入之前导出的文件继续填写或对比。
- **清空重置**：一键清空所有选择与姓名，并清除本地存储（有确认弹窗防误触）。
- **响应式布局**：在桌面端和移动端均可正常使用，雷达图会自适应容器尺寸。

## 快速开始

1. 下载或复制 `index.html`（本仓库中的完整 HTML 文件）。
2. 用现代浏览器（Chrome、Edge、Firefox、Safari 等）直接打开。
3. 在左侧输入姓名，逐对选择更贴近你的一端。
4. 右侧雷达图会实时反映各分类的得分。
5. 如需保存或分享，点击「导出档案」下载 JSON 文件。

> 无需服务器、无需安装依赖，完全离线可用。

## 使用指南

### 编辑区（左侧）

- **姓名 / 昵称**：输入后显示在右侧雷达图上方。
- **五级按钮**：点击任一按钮即选中该倾向；再次点击同一按钮可取消选择。
- **分类标题**：点击可展开 / 收起该分类下的所有特质对。
- **全部展开 / 全部收起**：一键控制所有分类的展开状态。
- **已选计数**：显示当前已选择的特质对数量（最多 200）。

### 展示区（右侧）

- **六张雷达图**：分别对应六大分类。
- **每个轴**：代表一个子分组，数值范围 0–100。
- **图形越靠外**：表示越偏向该子分组中左端特质的描述。
- **图形越靠内**：表示越偏向该子分组中右端特质的描述。
- **未选择的特质对**：按中间值 50 分计入，因此空白时图形为正多边形。

### 底部说明

页面底部居中区域列出了五级选择的含义、计分规则、雷达图解读方式及数据保存说明。

## 计分规则

每对特质的五个选项对应不同的分值：

| 选项 | 含义 | 分值 |
|------|------|------|
| ◀◀ | 完全偏向左端 | 100 |
| ◀  | 比较偏向左端 | 75  |
| ●  | 中间 / 不确定 | 50  |
| ▶  | 比较偏向右端 | 25  |
| ▶▶ | 完全偏向右端 | 0   |

- **子分组得分** = 该子分组内所有特质对得分的平均值。
- **分类得分** = 该分类下所有特质对得分的平均值（与按子分组数量加权平均等价）。
- **雷达图轴值** = 对应子分组的得分（0–100）。

## 数据格式

导出的 JSON 文件结构如下：

```json
{
  "app": "personality-radar",
  "version": 3,
  "name": "示例姓名",
  "choices": {
    "social-0-0": 2,
    "social-0-1": 1,
    "social-0-2": 0,
    "social-0-3": -1,
    "social-0-4": -2,
    "emotion-0-0": 2,
    ...
  },
  "exportedAt": "2026-10-07T10:04:51.831Z"
}
```

- **`choices`**：键为特质对 ID，值为数字（`2`、`1`、`0`、`-1`、`-2`）。
- **特质对 ID 格式**：`分类 key - 子分组索引 - 对子索引`，例如 `social-0-0` 表示社交互动分类下第 0 个子分组的第 0 对特质。
- **兼容性**：旧版本（v2）导出的 `'L'` / `'R'` 字符串数据在导入时会自动转换为数字。

## 自定义特质

所有特质对、子分组和分类都定义在 HTML 文件中的 `CATEGORIES` 数组里。你可以自由增删或修改：

```js
const CATEGORIES = [
  {
    key: 'social',
    name: '社交互动',
    color: '#6366f1',
    groups: [
      {
        name: '外向活力',
        pairs: [
          ['外向', '内向'],
          ['健谈', '寡言'],
          // ...
        ]
      },
      // ...
    ]
  },
  // ...
];
```

- **`key`**：分类唯一标识，用于生成特质对 ID。
- **`name`**：显示名称。
- **`color`**：该分类的主题色（十六进制）。
- **`groups[].name`**：子分组名称，会显示为雷达图的轴标签。
- **`groups[].pairs`**：二维数组，每个元素是一对 `[左端特质, 右端特质]`。

修改后保存文件，刷新页面即可生效。注意保持 ID 生成规则不变，否则已保存的数据可能无法正确匹配。

## 技术实现

- **纯静态**：HTML + CSS + 原生 JavaScript，无任何框架或库。
- **Canvas 绘图**：使用 Canvas 2D API 绘制雷达图，适配高 DPI 屏幕。
- **本地存储**：使用 `localStorage` 保存数据，键名为 `personality-radar-v2`。
- **响应式**：使用 CSS Grid 和媒体查询适配不同屏幕尺寸；窗口大小变化时雷达图会重新绘制。
- **数据迁移**：自动识别旧版 `'L'/'R'` 格式并转换为新版数字格式。
